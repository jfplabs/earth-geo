# 🌍 Earth Geo

**Explore the world through drone footage** — an interactive 3D globe showcasing aerial perspectives from around the globe.

## Features
- 🌐 Interactive 3D globe with day/night cycle
- 📍 Location markers for drone footage worldwide
- 🔍 Search locations, pilots, and tags
- 📤 Upload your own drone footage
- 👤 User accounts with auth
- 💬 Comments and likes on flights
- 📱 Mobile-friendly with touch support

## Tech Stack
- **Frontend:** Three.js, Vite, vanilla JS
- **Backend:** Node.js + Express (Railway)
- **Database:** Supabase (PostgreSQL)
